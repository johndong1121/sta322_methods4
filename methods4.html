des1 = svydesign(~page + know, weights = ~wt, fpc = ~ N + M_i, data = data)

By using two-stage cluster samplings, we have to pass multiple parameters so that R knows what to look at. In order to tell R to know that we are first sampling pages, we pass the “page” column as our largest cluster id, which says which sampled words belong to which cluster/page, and N (total number of pages) as our first fpc. Then, for our next id, we pass “words”, as our second id parameter so that R knows to know we are sampling words within each page. Then, we need to specify our second fpc, M_i, the total number of words on each page.

As for weights, we know that conceptually, two-stage cluster sampling consists of a random sample of \(n\) clusters, and within each of those clusters, there is some number of records sampled \(m_i\) among the cluster total \(M_i\). This gives us the sampling probability \(\pi_{ij} = \frac{n}{N} \frac{m_i}{M_i}\), or a weight of \(\frac{N}{n} \frac{M_i}{m_i}\), subbing 1331 pages for \(N\), 10 pages for \(n\), respective words-per-page totals for \(M_i\), and 20 for \(m_i\).

c. 

This statement is misleading because it makes some false assumptions about the population being sampled from. We are told are sample comes from a list of 1285 scholarly journals containing articles in the social and behavioral sciences. Therefore, the proportion we calculated describes the proportion of social and behavioral sciences that are published in a scholarly journal and use nonprobability sampling.

However, the statement goes on to use the estimated proportion to claim that this means that nonprobability is common enough for courts to have no problem with it being used. While it is likely for the majority of articles in social/behavioral science journals to use nonprobability sampling, this is a specific subdomain of articles. Additionally, social and behavioral sciences fundamentally rely more on voluntary participation, which would mean that these journals can disproportionally be more reliant on nonprobability sampling. We also don’t know if these articles are credible enough to be presented in court. A scholarly study can still be released in a journal, but then be deemed outdated or inaccurate later on. A stronger argument could be made if the articles were sampled from a population of articles deemed suitable for litigation by some outside metric, and if the sample wasn’t restricted to one field of study.

c.

The variance for the H-T estimator in the cluster sample is much greater because in our data, we can observe that each cluster each have a range of values that then vary drastically from the other clusters. This means that, when we get our estimator only using \(n=1\), i.e. only estimating the total from one cluster, we miss out on a majority of the range of \(y\).

This is different from the SRS model because, with SRS, the random process gives us a decent chance of collecting data from each cluster, while not guaranteed but much better than missing out on most clusters entirely.

Then, we can see how this is represented by looking at what is different between the two \(S^2\) formulas. In the cluster sample, we see that \(S^2\) has a much greater magnitude when the cluster totals deviate far from the average cluster totals, which is going to inevitably happen for this data because our clusters have egregious differences between their respective ranges of \(y\).

Our population consists of these three equally sized groups, called clusters, that are densely concentrated at 3 points. The first cluster’s y values are centered around ~3, the second around ~65, and the third around ~407. Each cluster’s y values are spaced far apart from each other, meaning that the total population has a wide variety of y values. However, if we want to make more consistent estimates of the total value for y in the population, we can use the fact that each of the groupings of y are consistently centered around a value. If we take a small sample from each group, we are more likely to get similar totals from each group to then estimate our population total. This is different than if we were to neglect the groupings, because then we would be assuming that the groups are similar when they are actually very different.

5.

Let \(I_i\) be the indicator that individual \(i\) is included in the sample. Then

\[ I_i = \begin{cases} 1, & \text{if individual } i \text{ is sampled},\\ 0, & \text{otherwise}. \end{cases} \]

The modified estimator is

\[ \widehat{t}_y^* = \sum_{i\neq i^*}\frac{I_i y_i}{p_i} + I_{i^*}w^*y_{i^*}. \]

Taking the expected value gives

\[ \begin{aligned} E\left(\widehat{t}_y^*\right) &= E\left( \sum_{i\neq i^*}\frac{I_i y_i}{p_i} + I_{i^*}w^*y_{i^*} \right)\\ &= \sum_{i\neq i^*} \frac{E(I_i)y_i}{p_i} + E(I_{i^*})w^*y_{i^*}. \end{aligned} \]

Since \(E(I_i)=p_i\) for every individual,

\[ \begin{aligned} E\left(\widehat{t}_y^*\right) &= \sum_{i\neq i^*} \frac{p_i y_i}{p_i} + p_{i^*}w^*y_{i^*}\\ &= \sum_{i\neq i^*}y_i + p_{i^*}w^*y_{i^*}. \end{aligned} \]

The true population total is

\[ t_y = \sum_{i\neq i^*}y_i+y_{i^*}. \]

Therefore, the bias is

\[ \begin{aligned} \operatorname{Bias}\left(\widehat{t}_y^*\right) &= E\left(\widehat{t}_y^*\right)-t_y\\ &= \left[ \sum_{i\neq i^*}y_i + p_{i^*}w^*y_{i^*} \right] - \left[ \sum_{i\neq i^*}y_i+y_{i^*} \right]\\ &= p_{i^*}w^*y_{i^*}-y_{i^*}\\ &= \left(p_{i^*}w^*-1\right)y_{i^*}. \end{aligned} \]

Because the original Horvitz–Thompson weight is

\[ w_{i^*}=\frac{1}{p_{i^*}}, \]

we can also write the bias as

\[ \boxed{ \operatorname{Bias}\left(\widehat{t}_y^*\right) = \left(\frac{w^*}{w_{i^*}}-1\right)y_{i^*} }. \]

Since \(w^*<w_{i^*}\), the bias is negative whenever \(y_{i^*}>0\). Therefore, the trimmed estimator is biased downward.
